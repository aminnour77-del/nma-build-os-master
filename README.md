# 🏗️ NMA BUILD OS - Enterprise Edition

Piattaforma gestionale in tempo reale per la Direzione Lavori e la gestione dei SAL (Stato Avanzamento Lavori) in cantiere.

## 🌟 Moduli Attivi
- **Torre di Controllo**: Dashboard direzionale per desktop.
- **Terminale Operatore**: Interfaccia field per iPad/Tablet.
- **Sicurezza**: Accesso con PIN multilivello.
- **Meteo Live API**: Telemetria ambientale satellitare automatica per ogni operazione.
- **Grafici Live**: Distribuzione fatturato generata in tempo reale con Chart.js.
- **Cloud Ready**: Configurato con porta dinamica per il deployment su Render.
